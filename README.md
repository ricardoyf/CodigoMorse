# Quiz de código Morse

Quiz web interactivo para aprender código Morse jugando.

- Cinco niveles: letras y palabras de 3, 4 y 5 letras.
- Dos mazos por nivel para aumentar la variedad.
- Abecedario Morse completo A-Z con audio para estudiar.
- Preguntas de codificación y decodificación.
- Sonido Morse mediante Web Audio.
- Diseño adaptable a móvil, tableta vertical y modo oscuro.

Publicado con GitHub Pages.
